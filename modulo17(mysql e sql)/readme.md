# Projeto - Jupyter Notebook

## 📌 Pré-requisitos

Ter o **Python 3** instalado na máquina.

---

## 📥 Instalação das dependências

No terminal, dentro da pasta do projeto, execute:

```bash
pip install -r requirements.txt
```

Esse comando irá instalar o **Jupyter Notebook** (definido no arquivo `requirements.txt`).

---

## 🚀 Como iniciar o Jupyter Notebook

Após a instalação, ainda no terminal, execute:

```bash
jupyter notebook
```

O navegador abrirá automaticamente com a interface do Jupyter.

Se não abrir, copie o link que aparecer no terminal (exemplo: `http://localhost:8888/...`) e cole no navegador.

---

## 🛑 Para encerrar o servidor

No terminal, pressione:

```
CTRL + C
```

Depois confirme com:

```
y
```
